# Zombie AI — Minecraft Java 26.3

Fabric mod that adds advanced AI goals to Zombies:

- wood harvesting and pickup
- simulated crafting of planks, crafting table, wooden sword and wooden pickaxe
- automatic equipment improvement
- hunting cows, pigs and sheep
- eating dropped meat when injured
- obstacle breaking while pursuing targets

## GitHub Actions

The workflow builds automatically on every push, pull request, or manual dispatch.
It uses Java 25 and Gradle 9.7.1, matching the current Fabric 26.3 example template/toolchain.

After the workflow succeeds, download the generated `.jar` from **Actions → Build Zombie AI → Artifacts**.
